# 全球化图标设计规范、量化评级模型与筛选打分表 (Icon Ranking System)

> **设计基准**: 严格遵循 **ISO 7001 (公共信息图形符号)**、**IEC 60417 (设备用图形符号)** 国际标准，结合出海智能锁与机械五金研发工程师的专业审美进行多维度量化评估与选拔。杜绝通俗卡通感与互联网安全俗套。

---

## 一、 图标评估与筛选量化标准 (4-Pillar Ranking Criteria)

| 维度编号 | 评估维度 (Dimension) | 权重 | 判定细则与量化要求 |
| :--- | :--- | :--- | :--- |
| **CR-01** | **跨文化/全球通用认知度 (Global Recognizability)** | **35%** | 符号具备超越语言与地域文化鸿沟的物理直觉认知，欧美、日韩、东南亚与拉美工程师第一眼即可准确理解其功能指向。 |
| **CR-02** | **机械与硬件工程契合度 (Hardware Engineering Fit)** | **25%** | 杜绝互联网“纯软件/SSL挂锁”的俗套符号；必须精准体现机械锁芯几何截面、装配卡扣、传动轴套或一线质检物理特征。 |
| **CR-03** | **极小尺寸高辨识与几何平衡度 (Visual Scalability)** | **20%** | 基于标准 24×24px 网格进行微调，在 14px~16px 菜单极小尺寸及移动端视网膜屏幕上依然线条利落、不糊点、重心居中。 |
| **CR-04** | **高级工业质感与去俗套化 (Aesthetic Elegance)** | **20%** | 告别粗糙单色块卡通感，主品牌标采用深空灰 `#0f172a` 至工程钛蓝 `#0284c7` 精准微渐变与精密内构，呈现硬核知识库气质。 |
